# ArcPass Product Definition

## Product Name

ArcPass

---

## Tagline

The first transaction layer for Arc.

---

## Problem

Arc Network uses native USDC for gas fees.

New users cannot perform their first transaction because they do not own USDC yet.

This creates a cold-start onboarding problem:
- no gas
- no first transaction
- no onboarding
- no ecosystem growth

ArcPass exists to solve this onboarding bottleneck.

---

# Product Vision

ArcPass is a public onboarding infrastructure layer for Arc ecosystem builders.

The system allows eligible wallets to execute their first onboarding transaction without requiring initial USDC gas ownership.

ArcPass is designed as ecosystem infrastructure, not as a consumer application.

---

# Target Users

Primary users:
- new Arc users
- developers onboarding users to Arc

Secondary users:
- Arc ecosystem dApps
- hackathon teams
- ecosystem partners

---

# Core MVP

The MVP only includes:

1. Wallet eligibility check
2. First transaction sponsorship
3. Anti-abuse protection
4. Transaction status tracking

---

# What ArcPass Is NOT

ArcPass is NOT:
- a trading platform
- a wallet
- a bridge
- a token project
- a yield protocol
- a DeFi application
- a full faucet replacement

---

# Core User Flow

1. User opens Arc-enabled application
2. User connects wallet
3. ArcPass checks wallet eligibility
4. ArcPass sponsors onboarding transaction
5. User successfully enters Arc ecosystem

---

# Public Good Value

ArcPass improves:
- ecosystem onboarding
- user activation
- developer conversion
- onboarding UX
- ecosystem accessibility

ArcPass is intended to function as reusable public infrastructure for the Arc ecosystem.

---

# Success Metrics

Important metrics:
